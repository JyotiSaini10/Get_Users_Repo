# Get_Users_Repo

GitHub Profile Finder

A modern and responsive web application that allows users to search for any GitHub profile and instantly view:

Profile information-->
* Avatar and bio
* Followers, following, and repository count
* Company, location, website, and social details
* Latest 3 repositories
* Direct links to repositories

Features-->
* Search any GitHub username
* Fetch real-time data from the GitHub API
* Display latest repositories dynamically
* Clean and responsive UI
* Error handling for invalid usernames
* Built with vanilla JavaScript (no frameworks)

Tech Stack-->
* HTML5
* Tailwind CSS
* JavaScript (ES6)
* GitHub REST API
* Live Demo
